下載 `SealGugu-V14.0.1-Windows-x64.zip`，完整解壓縮後執行 **SealGugu.exe**。

遊戲判定、譜面、音樂時鐘及三首歌曲維持原版。版本號採修訂版遞增，因為本次修正既有介面與操作回饋，沒有新增關卡或更動核心玩法。
