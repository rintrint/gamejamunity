海豹咕咕 **V14.1.0**，Unity 6.6 Windows 版。

下載 `SealGugu-V14.1.0-Windows-x64.zip`，完整解壓縮後執行 **SealGugu.exe**。

- **Alt + Enter** 切換視窗／無邊框全螢幕；切回視窗時恢復原本尺寸。左右 Alt 與數字鍵盤 Enter 均可使用，長按不會反覆切換。
- **F1** 顯示／隱藏左上角 FPS，預設隱藏，每半秒更新。主畫面、選曲和暫停時都可使用，不影響呼吸或節奏判定。
- 游標移到可操作的按鈕、勾選項及調整滑桿時，改成 **Windows 系統手形游標**，沿用系統游標樣式；離開後恢復箭頭。
- 彈出視窗後的背景按鈕、停用按鈕，以及捲動區域外的控制項，不會觸發手形提示。
- 保留 V14.0.1 的選曲防穿透、主畫面精簡、暖色 Hover 與上下按鍵空拍吃魚音效。

新增向下相容的桌面操作功能，因此由 V14.0.1 升為次版本 V14.1.0。歌曲、譜面、難度與判定規則維持不變。

驗證紀錄與限制見 repo 的 `Validation`；正式 Windows 包不含自動測試或實測記錄器。
