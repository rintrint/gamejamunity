# 海豹呼呼 V15.2.0

新增 **F2 場景／結局測試選單**，可直接測試上岸換氣及四種結局，不需要打完整首歌曲。

## 操作

- 按 **F2** 開啟或關閉選單；**Esc** 也能關閉。
- 15 個選項包括：開場吸氣、上岸撞飛垂釣者／換氣、大吸氣跨洞、最後上岸呼喚、瘦／中／胖游泳、三種體型缺氧、四種結局、主畫面肚子餓。
- 上岸從真正的撞飛動畫與音效開始，站穩後可連打補氣，時間到自動下海。
- 測試使用目前歌曲與難度，以及不死亡模式。可按「重播」反覆檢查。
- 原本的遊戲暫時保留；按「離開測試／返回原本遊戲」恢復原進度和音樂時間。原本已暫停的遊戲仍保持暫停。

## 介面與美術

- 移除主畫面「一口氣，游向你。」。
- Credits 移除「第二組」，五位組員姓名放大至 34 px，直接排列，不再出現捲動條。
- Credits 返回冰塊按鈕放大，保留提亮、陰影及手形游標 Hover。
- 飢餓 GIF 使用與正常海豹相近的藍紫色輪廓與粗度。描邊由 URP 著色器依每張原始動畫的透明輪廓繪製，維持原來 80 ms 每張的時序與等比例顯示；肚子聲結束仍恢復正常表情。

## 安裝

下載 `SealBreath-V15.2.0-Windows-x64.zip`，完整解壓縮後開啟 `SealBreath.exe`。保留旁邊的資料夾和 DLL。

Windows x64 / Unity 6.6（6000.6.4f1）/ URP 2D。新增玩家測試功能，因此由 V15.1.0 升級為次版本 V15.2.0。

## 驗證

- 原生 F2 測試通過 306 個檢查，涵蓋三首歌 × 三種難度 × 15 個場景選項，以及原進度／音樂還原。
- 鍵盤、音效、Alt+Enter、F1、系統游標與 21 個遊戲場景截圖通過；另驗證不同長寬比、GIF 三張原始影格及播完恢復正常表情。
- 核心 HTML 對照、難度／耗氧平衡、729 個上岸時序情境通過。
- 正式 Windows 包與測試包來自同一份程式，正式包保留 F2 功能、排除自動化診斷入口，並通過 ZIP CRC 檢查。
